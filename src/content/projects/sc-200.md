## About the book

This updated second edition prepares you for the SC-200 exam and helps demonstrate real-world mastery of the skills needed to work with stakeholders to secure IT systems and rapidly remediate active attacks.

It focuses on monitoring, identifying, investigating, and responding to threats in cloud and on-premises environments.

## Topics covered

- Threat management with Microsoft Defender XDR
- Cloud threat protection with Microsoft Defender for Cloud
- Security information and event management with Microsoft Sentinel
- AI-assisted security operations with Security Copilot
- Threat intelligence and incident response
